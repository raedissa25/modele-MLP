Ce projet présente un modèle de classification des signaux ECG basé sur un perceptron multicouche (MLP), entraîné sur un jeu de données prétraité issu de la base MIT-BIH. Le dépôt contient l’architecture du modèle, le code d’entraînement et d’évaluation, ainsi que les résultats obtenus sous forme de courbes, matrices de confusion et rapports de classification.

Les objectifs du projet incluent :

La préparation et l’analyse du dataset.

La conception et l'entraînement d’un modèle MLP.

L’évaluation de ses performances sur des signaux réels.

La génération de résultats visuels pour interprétation.

Le dépôt est structuré comme suit :

📁 résultats : courbes, matrices, distribution des classes, rapport de classification.

📁 modéle finale : fichier .h5 du modèle entraîné.

📁 entrainement et évaluation du modéle : notebooks et scripts d'entraînement/test.
